# OpenSpec Update

Update existing OpenSpec artifacts in a frame.

## When to use
- When the user wants to modify an existing artifact
- When design decisions change
- When tasks need to be added/removed/reordered
- When the user says "update", "modify", "change design"

## Steps

1. **Identify the frame and artifact:**
   - Which objective/frame?
   - Which artifact to update? (proposal, design, tasks, specs)

2. **Read current content:**
   - Read the existing artifact
   - Understand current state

3. **Apply changes:**
   - Make requested modifications
   - Maintain consistency with other artifacts
   - Update dependencies if tasks change

4. **Verify consistency:**
   - Check that all artifacts align
   - Update cross-references if needed
   - Ensure no contradictions

## Rules
- Maintain architecture-first approach
- Keep decisions traceable to anteproyecto
- Update dependencies when tasks change
- Document why changes were made

## Output
- Updated artifact(s)
- Summary of changes
- Any consistency issues found and resolved
