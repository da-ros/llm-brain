# Context — llm-brain (AI-Augmented Digital Brain)

## Qué es

Plataforma que permite a clientes (web y móvil) interactuar con un backend y LLMs
para gestión personal de conocimiento: cargar documentos (recetas médicas, facturas, fotos) y
recibir sugerencias inteligentes (comprar medicina, organizar gastos) basadas en RAG.

Modelo de negocio: dos perfiles de suscripción — **Free** y **Premium**.
Puede implementarse como un usuario con dos perfiles o dos usuarios con suscripciones distintas.

## Clientes

| Cliente | Tecnología | Tier | Funcionalidad |
|---------|------------|------|---------------|
| **Web App** | React + Chart.js | Premium | Charts de gastos, enfermedades, visualización de datos |
| **Mobile App** | React Native | Free / Premium | Consultas LLM, carga de archivos |

### Mobile — Free vs Premium

| Tier | LLM | Contexto | Archivos |
|------|-----|----------|----------|
| **Free** | llama.rn (Llama 3.2 3B, Q4_K_M on-device) | No | No |
| **Premium** | AWS Bedrock (Llama 3 8B fine-tuned) + RAG | Sí | Sí (imágenes + PDFs) |

### Capas clave

| Capa | Responsabilidad |
|------|-----------------|
| **API Gateway** | Rate limiting, routing, HTTPS (solo producción — AWS API Gateway managed) |
| **API Backend** | Auth, orchestración, endpoints REST, suscripciones |
| **Fine-Tuning Service** | Worker separado, schedule periódico, entrena LoRA con datos del cliente |
| **LLM Tool Layer** | RAG + Vector Store (encriptado) — soporte que el LLM cloud usa para contexto |
| **LLM Local** | llama.rn (Llama 3.2 3B Q4_K_M) en el dispositivo mobile — free tier, sin contexto |
| **LLM Cloud** | AWS Bedrock (fine-tuned + inference) — premium, con RAG |

## Datos del usuario

- **Tipos**: imágenes (fotos) y PDFs (recetas, facturas)
- **Procesamiento**: ETL extrae texto (OCR para imágenes, parser para PDFs) → JSON triples → Vector Store
- **Encriptación**: datos en RAG encriptados a nivel de aplicación (Fernet o similar)
- **TLS**: manejado por AWS API Gateway (certificado managed, sin costo adicional)

## Módulos de valor (del anteproyecto)

### Decision-Support Simulator
Módulo "what-if" que genera 3-5 escenarios con supuestos explícitos y trazabilidad.
Toma variables clave del contexto del usuario y produce escenarios deterministas con
un árbol de decisión sencillo.

### Life Analytics
Dashboard web (React) con visualización de correlaciones interactivas:
- Sueño vs productividad
- Reuniones vs tiempo de foco

Conecta con Google Calendar o ingiere un diario personal.
Cada módulo escribe resultados en la DB para trazabilidad posterior.

### Privacy & Scam Shield
Detector de phishing/fraude/scam basado en heurísticas + similitud de embeddings
sobre correos/mensajes/SMS de prueba. Muestra alertas emergentes y registra incidentes.

## Despliegue

| Entorno | Infraestructura | Propósito |
|---------|-----------------|-----------|
| **Local** | Docker Compose | Desarrollo y pruebas. Clientes → backend directo (sin API GW) |
| **Producción** | AWS ECS Fargate | Escalado, disponibilidad, load. API Gateway para routing |

### Decisiones de infraestructura

- **Docker** para todos los servicios (consistencia local ↔ prod)
- **ECS Fargate** para producción (serverless containers, sin managing EC2)
- **Fine-Tuning Service** como ECS task separado (escala independiente, alto procesamiento)
- **API Gateway**: AWS API Gateway en prod; sin API GW en local (directo al backend)

## Metodología

Enfoque iterativo e incremental (agile), combinado con investigación aplicada.
Cada paso indica qué se hará, cómo se ejecutará y para qué contribuye al logro global.

### Fases del proyecto

1. **Planificación y arquitectura**: Reunión de arranque, modelo C4, diagramas de agentes/contexto/flujo, repositorio Git. Resultado: arquitectura aprobada y hoja de ruta técnica.

2. **Pipeline "One-Tap Memory Distillation"**: ETL con Python + Tesseract OCR + parsers PDF/HTML. Cada ítem produce JSON con triples (sujeto-predicado-objeto) + metadatos normalizados. Meta: 100 documentos transformados.

3. **Almacén híbrido y RAG**: MongoDB Atlas Free para documentos, Chroma/MongoDB/Pinecone para embeddings. LangChain para búsqueda Top-k y recuperación semántica.

4. **LLM principal on-cloud + LLM on-device**: Fine-tuning LoRA (5 épocas) en AWS Bedrock (Llama 3 8B). Inferencia premium en AWS Bedrock. On-device con llama.rn (Llama 3.2 3B Q4_K_M) para free tier. Latencia objetivo: ≤2s on-device (>18 tok/s).

5. **Bucle de aprendizaje simbiótico**: Tres agentes MCP (Ingestor, Razonador, Evaluador). Al finalizar cada sesión, el Evaluador escribe feedback y genera lote semanal para fine-tuning incremental manual.

6. **Módulos de valor**: Decision-Support Simulator (what-if, 3-5 escenarios), Life Analytics (dashboard React + Chart.js, 2 correlaciones), Privacy & Scam Shield (heurísticas + similitud de embeddings).

7. **Validación**: Pruebas alfa internas, medición KPIs (tiempo de respuesta, precisión Top-3), video-demo.
