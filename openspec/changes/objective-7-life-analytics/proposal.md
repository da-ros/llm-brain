## Proposal: Life Analytics (Frontend)

### Context

Users need a web dashboard to visualize correlations between their personal data
points (sleep, productivity, health metrics). The dashboard uses React + Chart.js
to display interactive charts with at least 2 correlations.

### Why

1. **Visual insights**: Charts make patterns visible that raw data hides.
2. **Thesis OE7**: Anteproyecto specifies React + Chart.js dashboard with >=2
   interactive correlations (sleep/productivity).
3. **Premium feature**: Dashboard is exclusive to premium subscribers.

### Deliverables

- React dashboard with Chart.js
- >=2 interactive correlations (sleep/productivity, health/focus)
- Data visualization components (line, bar, scatter charts)
- Responsive design (desktop-first, mobile-friendly)
- Integration with backend data API

### Non-Deliverables

- Real-time streaming charts
- Custom chart types (beyond Chart.js)
- Data export (CSV/PDF)
- Mobile app dashboard (separate frame)
